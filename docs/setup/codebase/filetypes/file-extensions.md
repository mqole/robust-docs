# File Extension Cheat Sheet

This page serves as a handy guide to which file extensions are used for which file types.

<WipHeader text="To be so honest I need to google what some of these are. -mqole"/>

## Project Files

| Extension | File Type |
| - | - |
| .md | Markdown file used to display formatted text. This page you're reading right now is a `.md` file!
| .sln / .slnx | File containing the project solution.
| .py | Python script file.
| .nix
| .bat
| .sh
| .ps1

## Code Files

| Extension | File Type |
| - | - |
| .cs | C# file.
| .csproj
| .xaml | File format for rendering a UI interface.
| .xaml.cs | C# file which automatically detects a same-named `.xaml` file and connects the UI interface to the game code.

## Resource Files

| Extension | File Type |
| - | - |
| .yml | Entity Prototype file. In some directories, these are used for attribution.
| .ogg | Audio files.
| .toml | Server configuration file.
| .otf / .ttf | Text font file.
| .ftl | File storing locale strings used for translation into various languages.
| .xml | Pages formatted for the in-game guidebook.
| .rsi | 'Robust Station Image'. A folder format used to store `.png` sprite states. Requires a `.json` attribution file.
| .png | Sprites and other images.
| .json | Attribution file for image.
| .swsl | 'Space Wizards Shader Language'. Animation rules for in-game shaders.
| .sf2 | Soundfont file for use with MIDI instruments.
